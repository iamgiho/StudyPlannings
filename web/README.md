# 온플랜 HTML 버전

이 폴더는 HTML·CSS·JavaScript 파일만으로 실행되는 독립 웹앱입니다. Next.js·React·Vercel 서버 API는 필요하지 않습니다. Supabase가 기록의 원본 저장소와 권한 검사를 담당합니다. Google 폼이나 브라우저 localStorage를 학습 기록 저장소로 사용하지 않습니다.

## 사용

1. 관리자 → 기존 코치 계정 로그인.
2. 학생 추가 → 이름·학년만 등록. 학생 이메일·비밀번호·Auth 계정은 생성하지 않습니다.
3. 학생 현황 → 학생 링크 → 새 링크 발급 → 해당 학생에게 전달.
4. 학생은 전용 링크를 열고 이름·학년을 확인한 뒤 오늘 과제를 체크합니다.
5. 관리자는 실시간 갱신 및 15초 폴링으로 기록을 확인합니다. 수행 기록은 사이트를 닫아도 Supabase에 남습니다.

개인 링크는 256비트 무작위 인증 수단입니다. 이름만으로 다른 학생의 기록을 찾을 수 없습니다. 링크는 URL fragment에 담겨 정적 호스팅 서버로 전송되지 않고, 저장소에는 해시만 보관합니다. 180일 만료·재발급·즉시 중지 기능이 있습니다. 링크를 가진 사람은 해당 학생으로 기록할 수 있으므로 학생 본인에게만 전달하세요. 관리자 인증을 대체하는 링크는 아닙니다.

## 실행

프로젝트 루트의 `실행하기.bat`를 더블클릭한 뒤 http://127.0.0.1:8766/ 에 접속합니다. 또는 Node 설치 환경에서 `pnpm dev`를 실행합니다. Supabase에 접속하려면 인터넷 연결이 필요합니다. localhost 주소는 해당 PC에서만 열리므로 학생 휴대폰에 전달할 링크는 실제 배포된 HTTPS 주소에서 발급하세요.

이 폴더의 내용을 정적 웹 호스팅에 그대로 올릴 수 있습니다. 일반적인 모듈 JS·폰트 MIME 유형을 지원해야 하며, HTTPS가 권장됩니다. Vercel을 쓴다면 이 폴더의 `vercel.json`은 서버 빌드 없이 파일만 배포하도록 설정합니다. GitHub Pages 등 호스팅 정책의 사업용 이용 가능 여부는 별도로 확인해야 합니다.

## 기능

학생: 오늘 체크·수정, 월~일 플래너, 다음 주 미리보기, 주·월·과목 통계, 공개 피드백, 요약 공유 의사, 성장 단계에 따른 계획 초안·배분 수정.

관리자: 학생 등록·검색·필터, 체크 현황, 개인 링크 발급·중지, 계획 작성·확정·재배치·취소, 단계 설정, 상담 기록, 주·월 리포트 작성·승인·복사·PDF 다운로드, 변경 이력.

PDF는 서버가 아니라 브라우저에서 생성합니다. 다운로드 전에 Supabase의 `export_report`가 담당 코치·리포트 승인·현재 공유 동의를 검사합니다. 서버 전용 키는 HTML에 없습니다. 한글 PDF를 위해 약 6 MB의 정적 폰트를 최초 요청하며, 생성된 PDF는 약 3.1 MB입니다.

## 개발 및 DB 설정

루트에서 `pnpm install --frozen-lockfile`, `.env.local` 공개 설정 후 `pnpm build`로 라이브러리 번들과 공개 `config.js`를 준비합니다. 이미 번들·설정·폰트가 있는 배포 폴더는 다시 빌드할 필요가 없습니다. `config.js`에는 URL·publishable key만 넣습니다.

기존 DB에는 `20261109045935_student_portal_links.sql`, `20261109050829_students_without_auth_accounts.sql`을 순서대로 적용합니다. 신규 DB에는 기본 `001_initial.sql`부터 적용합니다. 기존 운영 DB에 기본 SQL을 다시 실행하지 마세요.

코치 프로필은 Auth ID를 두 열에 연결합니다:

```sql
insert into public.profiles(id,auth_user_id,name,role)
values ('COACH_AUTH_UUID','COACH_AUTH_UUID','코치 이름','coach');
```

학생은 관리자 화면에서 등록합니다. 기존 학생 Auth 계정은 보존되지만 새 학생에는 필요하지 않습니다. 원래 Next.js 소스는 루트 `app/`, `components/`에 참고·복구용으로 유지합니다.
